# Interlúdio

Dados agregados, scripts e material de apoio do plano de negócio da **Interlúdio**, uma luderia (casa de jogos de tabuleiro), elaborado como trabalho de conclusão de curso.

- `texto/`: versão final do trabalho em PDF, com as figuras, os gráficos, as planilhas e os quadros
- `dados-agregados/`: bases tratadas e resultados das coletas (B1 a B5)
- `_src/`: scripts de coleta, tratamento e análise
- `site-apresentacao/`: código do site da apresentação, publicado em <https://eusouopeu.github.io/interludio/>
